faq:
  - q: The Alarm lamp came on and the Wi-Fi icons are not lit
    a: The connection did not finish. Check that the router supports WPS and that you pressed its WPS button within two minutes. If several routers are nearby, press WPS on only one of them. Then repeat the connection from step 5.
  - q: The printer does not see my Wi-Fi network
    a: The printer works only on the 2.4 GHz band and does not support IEEE 802.11ac, 802.11a or 802.11n on 5 GHz. Check that the router broadcasts a 2.4 GHz network.
  - q: Does the computer have to be connected to the router first
    a: Yes. Before setup make sure the computer and the router are already connected. If the router is set to IEEE 802.11n only, WEP or TKIP security will not work, so change the security type on the router.
  - q: Can I use USB together with Wi-Fi
    a: Yes, Wi-Fi and USB can work at the same time.

PIXMA TS3300 series printers join a home network without a cable. It is easiest when the router has a WPS button. If it does not, use step 9: connecting through the Direct button and Canon's setup software.

## Switch the printer on

![Printer control panel with the ON lamp lit and the Stop button next to it](step-1.svg)

Press the power button and make sure the ON lamp is lit. If the printer is cleaning the head or busy with another process, wait. If the ON lamp is blinking, press the **Stop** button.

## Check that the router broadcasts 2.4 GHz

The printer does not support 5 GHz Wi-Fi (IEEE 802.11ac, 802.11a, 802.11n at 5 GHz). You need a 2.4 GHz network, so enable that band in the router settings if needed.

## Get the WPS button on the router ready

Find the WPS button on the router and make sure you can reach it. You press it later, within two minutes, not now.

## Find the Network button

![Printer panel with the Network button and its Wi-Fi icon highlighted, the display to the right](step-4.svg)

Find the **Network** button with the Wi-Fi icon on the printer panel.

## Hold the Network button

![A finger holding the Network button while the Wi-Fi icon blinks on the display](step-5.svg)

Press and hold the **Network** button until the Wi-Fi icon starts to blink on the display, then release the button.

## Press WPS on the router

![A router with its WPS button and a two-minute timer beside it](step-6.svg)

Within two minutes ({{timer 2m}}) press and hold the WPS button on the router. See the router's manual for how exactly to press it.

## Wait for the connection

![Printer display with the Wi-Fi icon and the signal strength icon lit](step-7.svg)

When the connection is complete, the Wi-Fi icon and the signal strength icon on the display light up. If the Alarm lamp comes on, repeat steps 5-6.

## Continue the setup on the computer

If you are setting the printer up with Canon software, go back to it. In Windows click the program icon in the taskbar, in macOS the icon in the Dock, and follow the on-screen prompts.

## Or connect without WPS with the Direct button

![Printer with the Direct button highlighted and a blinking icon on the display](step-9.svg)

This replaces steps 3-8 and works through Canon's setup software on the computer. Press and hold the **Direct** button on the printer until the icon on the display blinks, then release it. Return to the software and go through the setup steps. It is not available on Chrome OS, Windows RT and Windows 10 in S mode.
