Almost everything is controlled from the remote: the power button, Mode, the temperature arrows, Fan Speed and Timer. The example follows the LG manual for wall-mounted air conditioners. Some buttons and modes depend on the model: for example, heating exists only on cooling and heating models.

Point the remote at the signal receiver on the indoor unit.

## Insert the batteries and set the time on the remote

![Air conditioner remote with the Set/Cancel button highlighted, next to the open battery cover and a display](step-1.svg)

Insert AAA batteries with the correct polarity. A clock icon blinks on the display. Use the up and down arrow buttons to set the time and press <kbd>Set/Cancel</kbd>. The timers need the current time.

## Switch the air conditioner on with the power button

![Remote pointed at the indoor unit of the air conditioner, the power button is pressed](step-2.svg)

Point the remote at the signal receiver on the indoor unit and press the power button.

## Select the cooling mode

![Remote with the Mode button highlighted and a snowflake icon for cooling](step-3.svg)

Press <kbd>Mode</kbd> until the cooling icon (a snowflake) appears on the display. Use the up and down arrows to set a temperature below the room temperature. If the room cools too slowly, there is a quick mode (the H'Cool or Jet button, depending on the remote): a strong airflow for about 30 minutes.

## Select the heating mode

Press <kbd>Mode</kbd> until the heating icon (a sun) appears and set the temperature with the arrows. Heating is available only on cooling and heating models. While heating, the unit may run a defrost cycle, which takes about 15 minutes.

## Select the dry mode

![Remote with the Mode button highlighted and a water drop icon for dehumidification](step-5.svg)

Press <kbd>Mode</kbd> until the drop icon appears. In this mode the air conditioner removes excess moisture and picks the temperature and fan speed itself. You cannot set the temperature and it is not shown on the display.

## Select the fan mode

Press <kbd>Mode</kbd> until the fan icon appears. Fan mode only circulates the air in the room and does not change its temperature.

## Change the fan speed

Press <kbd>Fan Speed</kbd> until you get the speed you want: from low to high, and Natural Wind (automatic speed). In some modes the speed is not available, for example in auto operation and in dry mode.

## Set the switch-on time

![Remote with the Timer and Set/Cancel buttons highlighted, a clock next to it](step-8.svg)

Press <kbd>Timer</kbd> until the ON icon blinks at the bottom of the display. Set the time with the up and down arrows and press <kbd>Set/Cancel</kbd>. The display keeps showing the current time and the ON icon. The timer works only after you have set the time on the remote.

## Set the switch-off time

Press <kbd>Timer</kbd> until the OFF icon blinks. Pick the time with the arrows and press <kbd>Set/Cancel</kbd>. The on and off timers can be set together.

## Cancel the timer

To cancel one timer, press <kbd>Timer</kbd> until its icon blinks and press <kbd>Set/Cancel</kbd>. To clear all timers, just press <kbd>Set/Cancel</kbd>.
