Menu names depend on the model and firmware: the most common path is used below, with other variants noted in the steps. You do not need to touch any other settings to change the name and password.

## Connect to the router

Connect your phone or laptop to the router over Wi-Fi or with an Ethernet cable. If you change the password over Wi-Fi you will be disconnected after saving.

## Open the router page

![Browser with the router address typed in the address bar](step-2.svg)

Type `tplinkwifi.net` or `192.168.0.1` in the browser's address bar.

## Log in with the admin password

![Login page with a password field and a login button](step-3.svg)

Enter the router admin password and log in. If this is your first login the router asks you to create an admin password.

## Open the Wi-Fi settings

![Router web page with the Advanced tab and the Wireless row in the side menu highlighted](step-4.svg)

On most models open {{Advanced > Wireless > Wireless Settings}}. On other models look for {{Basic > Wireless}}, and on older ones the network name is under Basic Settings and the password under Wireless Security. On Wi-Fi 8 routers the path is {{Wi-Fi > Main Network}}.

## Enter the new name and password

![Wireless settings form with the network name and password fields highlighted](step-5.svg)

Type the new network name (SSID) and password. The password is case-sensitive. The 2.4 GHz and 5 GHz bands may have separate settings: if the page shows several bands, change each one or turn on Smart Connect to use one name.

## Save the settings

![The Save button at the bottom of the settings page highlighted](step-6.svg)

Click **Save**. Devices connected over Wi-Fi are disconnected.

## Reconnect your devices

![Phone Wi-Fi list with the home network highlighted](step-7.svg)

On phones, laptops and TVs pick the network and enter the new password. If a device remembers the old password, forget the network first.

> [!TIP]
> For a strong password use at least 12 characters with letters, digits and symbols. Store it somewhere safe.
